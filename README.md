# Robótica con kidsIOT

Material de robótica educativa para Primaria (8-13 años) con el kit **Kidsbits STEAM Engineering IoT** (placa ESP32 kidsIOT) y **MicroBlocks**.

**Abrir el recurso:** https://pablomoraga.github.io/roboticakidsiot/

- **Para empezar**: el kit, la placa, sensores y actuadores, y MicroBlocks.
- **Comenzamos**: 12 actividades con sensores, sin montaje.
- **Retos**: 8 máquinas con montaje paso a paso y dos retos finales.
- **Para saber más**: información técnica y metodología para el profesorado.

En `descargas/` están los 25 programas de MicroBlocks (.ubp), el proyecto de eXeLearning (.elpx) y el diario de ingeniero.
