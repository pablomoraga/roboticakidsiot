Reto 2 · Mezclador

Una hormigonera que se enciende con el dedo

Tu misión

Haz que el mezclador se encienda con un toque y se apague con otro toque.
variablesinterruptor

Necesitas: Placa, cable USB, sensor táctil, servo de 360° y piezas del reto.
Librerías: KidsIOT Engineering

Montaje paso a paso

El montaje tiene 17 pasos. Usa las flechas, desliza las imágenes o pulsa un número. Empieza por P: reúne todas las piezas antes de montar.

P1234567891011121314151617

Los colores de algunas piezas pueden no coincidir con los de tu caja.

Conecta

Conecta el sensor táctil al puerto 2 y el servo de 360° a S2.

Los cables del servo

Marrón a G, rojo a V y naranja a la señal (S1 o S2).

La ciencia de tu máquina

Girar para mezclar

Cuando el bombo gira, los materiales suben por la pared, caen y se mezclan. Si gira demasiado rápido, todo se queda pegado a la pared y ya no se mezcla. Por eso las hormigoneras giran despacio.

1 Prueba el motor

Predice, prueba y explica

  1. Predice: si solo escribes «si tocas, gira; si no, para», ¿el mezclador seguirá girando al quitar el dedo?
  2. Prueba: ejecútalo y observa la máquina.
  3. Explica: ¿por qué hace falta «recordar» si está encendido o apagado?

2 Diseña tu programa

Piensa primero cómo debe comportarse tu máquina. Si te atascas, abre las pistas una a una.

Pista 1
Necesitas que la placa recuerde si el mezclador está encendido. Para recordar se usan las variables.
Pista 2
Cada vez que tocas, la variable cambia al contrario: de falso a verdadero o de verdadero a falso. Usa el bloque no.
Pista 3
No olvides esperar a que quites el dedo, como en el contador de toques de Comenzamos.
Ver una posible solución

3 Caza el error

Este programa tiene un fallo

Este programa debería encender y apagar el mezclador con cada toque, pero se vuelve loco: se enciende y se apaga muchas veces.

Pista
¿Cuántas veces se repite «por siempre» mientras tu dedo toca el sensor?
Solución
Mientras el dedo está encima, el bucle da muchas vueltas y cambia la variable cada vez. Hay que esperar a que se toque y después esperar a que se suelte (bloques «esperar hasta»).

Niveles del reto

Elige tu nivel. Puedes empezar por el básico y subir cuando lo consigas.

BásicoUn toque enciende y otro toque apaga.
MedioQue la pantalla muestre «MEZCLANDO» o «PARADO».
ExpertoQue cada toque cambie el sentido de giro, como una hormigonera que mezcla y luego descarga. Sin pistas: ¡tú decides cómo!

Para el docente

El sensor táctil detecta el dedo a través de papel o plástico fino. El error típico de este reto (cambiar la variable muchas veces con un solo toque) es el que se trabaja en «Caza el error».

Autoevaluación

Responde y comprueba. Si fallas alguna, vuelve a mirar el reto.

1. ¿Para qué sirve la variable «encendido»?

  • A) Para medir la velocidad
  • B) Para recordar si está en marcha
  • C) Para contar toques
Comprobar respuesta
B) Guarda si el mezclador está encendido o apagado.

2. ¿Qué hace el bloque «no»?

  • A) Cambia verdadero por falso y al revés
  • B) Para el programa
  • C) Borra la variable
Comprobar respuesta
A) Invierte el valor: verdadero pasa a falso y falso a verdadero.

3. ¿Por qué las hormigoneras giran despacio?

  • A) Para gastar menos
  • B) Para que los materiales caigan y se mezclen
  • C) Porque pesan mucho
Comprobar respuesta
B) Si girasen muy rápido, todo se quedaría pegado a la pared.
